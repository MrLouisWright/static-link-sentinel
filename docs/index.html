static-link-sentinel

Fail CI on broken links before you deploy.

Crawls your built static site (dist/, build/, out/, public/, _site/) for broken internal links, missing assets, missing #anchors and paths whose letter case only works on macOS. With --external it checks outbound links for 404s and redirect chains, showing every hop. No server needed: it resolves URLs the way Netlify, Vercel, GitHub Pages and Cloudflare Pages do.

$ npm i -D static-link-sentinel
Read the docs View on npm Source on GitHub

01 The problem

/img/Logo.png works on your Mac and 404s on the Linux CDN. A typo'd slug, a renamed heading anchor or a dead outbound link ships because nothing checks the built output.

static-link-sentinel reads the files you are about to deploy, resolves every reference exactly like your host will, and fails CI with a fix line such as "did you mean /blog/post-1/?".

02 Features

01

Internal links & assets

HTML, CSS url()/@import, web manifests, sitemap*.xml and robots.txt are all checked against the build.

02

Case-mismatch detection

Case-sensitive matching like Linux hosts, with a dedicated case-mismatch error instead of a silent pass.

03

#anchor checks

Missing fragments are reported with a "did you mean" suggestion.

04

External links

--external HEADs each unique URL with GET fallback, per-host throttling, retries and a 24 h cache, recording every redirect hop.

05

Host-aware resolution

Clean URLs, index.html, trailingSlash, basePath, Netlify _redirects and vercel.json.

06

Markdown sources

--sources checks links and #heading anchors in .md / .mdx before you even build.

07

Reports for CI

JSON, SARIF and Markdown output (great for job summaries and PR comments).

08

Zero dependencies

CLI, API, Vite and webpack plugins, and a GitHub Action. Node ≥ 18.

03 Usage

# Auto-detect the build dir

$ npx static-link-sentinel

# Check external links too

$ npx static-link-sentinel dist --external --site-url https://example.com

# GitHub Pages project site

$ npx static-link-sentinel dist --base-path /my-repo

# Markdown before build

$ npx static-link-sentinel --sources docs content README.md

04 CI / GitHub Action

name: Links
on: [push, pull_request]
jobs:
  links:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20 }
      - run: npm ci && npm run build
      - uses: MrLouisWright/static-link-sentinel@v1
        with:
          dir: dist
          site-url: https://example.com
          external: ${{ github.event_name == 'push' }}
          fail-on: error
          sarif: links.sarif
      - if: always()
        uses: github/codeql-action/upload-sarif@v3
        with: { sarif_file: links.sarif }

05 Options & flags

FlagDescription
-b, --base-path <path>Site is served under a sub-path (e.g. /docs)
-s, --site-url <url>Production URL: absolute links to it are checked as internal
--trailing-slash <m>always | never | ignore (default: ignore, or vercel.json)
--clean-urlsHost serves /about for about.html
--orphansReport pages no other page links to
-e, --externalAlso check external links (HEAD, GET fallback)
--concurrency <n>Parallel external requests (default 8)
--per-host <n>Parallel requests per host (default 2)
--host-delay <ms>Minimum gap between requests to one host (default 150)
--timeout <ms>Per-request timeout (default 10000)
--retries <n>Retries on timeout/5xx/429 (default 2)
--user-agent <ua>User-Agent for external requests
--skip <pattern>Don't fetch matching external URLs (repeatable)
--cache-file <file>External result cache (default .link-cache.json)
--cache-ttl <hours>Cache lifetime (default 24)
--no-cacheDon't read or write the cache
--sources [pattern...]Also scan markdown/mdx under the project
-i, --ignore <pattern>Ignore matching URLs (glob, substring or re:regex; repeatable)
-c, --config <file>JSON config
--fail-on <level>error | warn | none (default error)
--jsonJSON report on stdout
--sarif [file]SARIF 2.1.0 to stdout or file
--markdown [file]Markdown summary to stdout or file
-q, --quietHide info-level findings
